tier表のデッキを→untapへ

デッキのページでブックマークをクリックすると、日本語のデッキを英語名に変換して、untap.in にそのまま取り込めます。AI もアカウント登録も要りません。

使い方はどのゲームも3段階

  1. 1 · デッキのページブックマークを押して「コピー」ゲームごとに使えるサイトは下で選べます
  2. 2 · untap.inもう一度ブックマークを押して「取り込む」同じゲームのデッキ画面で。最後に Save
  3. 3 · 足りないとき「照合・登録を頼む」untap にあるか調べて、無ければ登録してもらえます

準備（最初の1回だけ・PC のブラウザ）

untapへ転送

このボタンをブックマークバーまでドラッグ。毎回最新版を読み込むので、今後の更新で登録し直す必要はありません。

ブックマークバーが出ていなければ Ctrl+Shift+B（Mac は ⌘+Shift+B）。ドラッグできないときは、下のコードをコピーして、ブックマークバーを右クリック →「ページを追加」（Firefox は「ブックマークを追加」）→ URL 欄に貼り付け、名前は「untapへ転送」に。

ゲームを選ぶ

遊ぶゲームを押すと、そのゲームの手順が出ます。

使えるサイト

  • cardrush の Tier 表おすすめ表からデッキタイプ（例：青ロックス）の記事を開く。記事には大会の優勝デッキが何個も並んでいて、まとめて取れます
  • cardrush のデッキ一覧1デッキデッキを1つ選んで、そのデッキのページを開く
  • TCG PORTAL の大会結果1デッキ大会 → 入賞デッキのページを開く。デッキ・環境分析からも

手順

  1. 上のサイトでデッキのページ（または記事）を開き、ブックマーク「untapへ転送」を押す。
    • 右上にパネルが出て、ページ内のデッキが並びます（初回だけ英語名データの取得に数秒）
    • 記事でデッキが多いときは、パネルのデッキ名（「↓ 場所へ」）を押すと、ページのそのデッキの位置へ移動します
  2. 使いたいデッキの「コピー」を押す。
    • リーダー・デッキ50枚・ドン!!10枚がそろっているか「枚数チェック」が出ます
    • 好きなドン!!を使うときは、出てきた「ドン!!カード」欄に untap で「Don card」と検索したドン!!の「名前 (版)」（例 Don!! Card - Luffy (op01)）を入れて「このドン!!で保存して再コピー」。次回もそのドン!!になります
  3. untap.in で「One Piece Card Game」のデッキを開き、下の「untap に取り込む」の手順へ。
英語名が見つからないとき・注意
  • パネルでオレンジ色のカードは英語名が見つからなかったもの（出たばかりの弾に多い）。名前を押すと公式の英語版カードリストが型番で開きます
  • 型番は [op16-042] のように角括弧で入ります。まれに別の版（パラレルなど）が入ることがあるので、取り込み後に型番が合っているかざっと確認を
  • 「英語名データの一覧を取得できませんでした」は GitHub の回数制限。1時間ほど空けて再実行

手順

  1. デッキのページでブックマークを押す。
    • 英語名を英語の wiki でカード番号から調べます（初回は数秒〜数十秒、30日保存）
  2. 「コピー」を押す。

  3. untap.in で「Cardfight!! Vanguard」のデッキを開き、下の「untap に取り込む」の手順へ。
英語名が見つからないとき・注意

  • カード番号 (dz-bt01/010) を付けて入れるので、untap に同じ版があればその版が入ります

手順

  1. デッキのページでブックマークを押し、使いたいデッキの「開く」を押す。
    • 「英語名データにある 12 / 16 種類」のように出ます。カードごとにデータにあり・データに無し・要確認の印が付きます
    • データに無いカードも、他の人が untap に登録済みなら、次の取り込みのときに番号で見つかります
  2. 「untap用にコピー」を押し、untap.in で「Weiß Schwarz」のデッキを開いて、下の「untap に取り込む」の手順へ。
    • 取り込むときに、データに無いカードを untap に番号で問い合わせ、見つかったものは untap の英語名で入れます
  3. それでも入らなかったカードだけ、「照合・登録を頼む」。
    • フォームが開くので、内容を確認して「送信」。名前（任意）を入れておくと次回も入ります
    • untap に候補があるカードは、候補の画像が並びます。同じカードなら「これを使う」を選んで「選んだカードで取り込み直す」。依頼しなくても入ります（選んだ名前は依頼を送ると登録担当にも届きます）
    • 依頼に入れたくないカードは、チェックを外します
    • 候補の画像は押すと大きくなります。untap の画面で確かめたいときは、パネル右上の「–」で小さくするか「⇆」で左に移すと、選んだ内容を残したまま untap が見えます（小さくした帯はタイトルをつかんで上下に動かせて、位置は次回も覚えています）
    • デッキのページの「untap で取り込む前に頼む」からも送れますが、ふつうは取り込んでからで十分です
ヴァイスは依頼がいちばん効きます。一度登録されたカードは、それ以降は誰が取り込んでも英語名で入るようになります。よく使うタイトルほど、依頼はだんだん要らなくなります。
英語名を自分で入れられないのはなぜ？
  • untap はカード名で探すので、untap に登録されている名前と一字一句同じでないと入りません。英語名は登録担当が登録したときの名前を使います
  • 各カードの「効果を読む（HoC）」は、ファンの英訳サイト Heart of the Cards のページです。読むだけにしてください（転載禁止なので、訳を写して使うことはできません）

untap に取り込む（全ゲーム共通）

  1. untap.in にログインし、Decks から同じゲームのデッキを開く（新しく作ってもOK）。
  2. デッキの画面でブックマーク「untapへ転送」を押し、「コピーしたデッキを取り込む」。
    • 貼り付け・「Clear existing cards in deck」のチェック・「Import Cards」まで自動で行い、デッキ名も入れます
    • 最初の1回だけ、Chrome から「クリップボードの読み取り」の許可を聞かれるので「許可」を
    • ゲームが違うデッキ画面だと止めます（例：ポケモンのデッキ画面にワンピースを入れようとしたとき）
  3. 内容を確認して、untap 右上の「Save」を押す。
取り込めなかったカードがあるとき：パネルに一覧と「untap にあるか調べて、無ければ登録してもらえます」の枠が出ます。名前（任意）を入れて「照合・登録を頼む」を押し、開いたフォームで「送信」。登録が済んだら、untap のデッキ画面でブックマーク → 履歴の「このデッキに取り込む」でもう一度取り込むと入ります。1枚も一致しないときも同じです。
手動で取り込むとき
  • untap のデッキ画面 → Import / Export → Paste Deck に貼り付け →「Clear existing cards in deck」にチェック →「Import Cards」→「Save」

便利な機能

  • 履歴untap で取り込んだデッキは、untap の画面でブックマークを押したパネルに最大100件残ります（デッキ名・成績・元のページつき）。無料プランは10デッキまでなので、入れ替えたデッキも「このデッキに取り込む」ですぐ戻せます。
  • 対戦用メモコピー後の「対戦用メモをコピー」で、元のページと「英語名 → 日本語名」の一覧をコピー。untap の「Play Notes」タブに貼ると、対戦中に日本語名を見られます。
  • デッキを比べる「別のデッキと比べる」に別のデッキ（untap の Export Deck の中身など）を貼ると、何が何枚違うかを日本語名で表示します。
  • 場所へ移動1ページにデッキが何個もあるとき、パネルのデッキ名（「↓ 場所へ」）を押すとページのその位置へ移動します。
  • うまく動かないパネルのエラーの下、またはパネル下部の「状況を報告用にコピー」を押し、そのまま作った人に送ってください（版・ページの URL・エラー内容が入ります）。
