tier表のデッキを→untapへ

デッキのページでブックマークをクリックすると、日本語のデッキを英語名に変換して、untap.in にそのまま貼れる形でコピーします。AI も登録も要りません。

対応サイト

  • ONE PIECEcardrush（cardrush.media/onepiece）のデッキタイプ記事・デッキ詳細ページ
  • 4ゲームTCG PORTAL（tcg-portal.jp）の遊戯王・ワンピース・ポケモン・デュエマの大会結果・投稿デッキのページ
  • 遊戯王・デュエマDECK MAKER（deck-maker.com）のデッキ画面。ガチまとめのデッキは「コピーしてデッキを作成」で DECK MAKER を開いてから実行
  • ポケモンポケカ公式の「デッキを表示」ページ（pokemon-card.com/deck/confirm.html/…）。ポケ飯の「デッキ作成」、トレカの地図の「デッキレシピはこちら」から開くページ
  • ポケモンcardrush（cardrush.media/pokemon）のデッキタイプ記事・デッキ詳細ページ
  • ヴァンガード公式サイトの入賞者デッキレシピ（cf-vanguard.com/deckrecipe/…）。チーム戦のページなら3人分まとめて出ます
  • ヴァンガードDECK LOG（decklog.bushiroad.com/view/デッキコード）。公式ページやブシナビから開いたデッキ表示ページで実行。ログインは不要です
  • ヴァイス公式サイトのデッキレシピ（ws-tcg.com/deckrecipe/…）と DECK LOG。ヴァイスだけは自動変換ではなく、英語名を確認しながら作る方式です（下の「ヴァイスシュヴァルツの使い方」）

準備（最初の1回だけ・PC のブラウザ）

untapへ転送

このボタンをブックマークバーまでドラッグ。このブックマークは毎回最新版を読み込むので、今後の更新で登録し直す必要はありません。

ブックマークバーが出ていなければ Ctrl+Shift+B（Mac は ⌘+Shift+B）。ドラッグできないときは、下のコードをコピーして、ブックマークバーを右クリック →「ページを追加」（Firefox は「ブックマークを追加」）→ URL 欄に貼り付け、名前は「untapへ転送」に。以前の版を登録済みなら、このコードで置き換えてください。

予備のブックマーク（「本体を読み込めませんでした」と出たサイト用）
untapへ転送（予備）

全機能を中に入れた版です。どのサイトでも動きますが、自動更新されないので、更新があったら登録し直してください。

使い方

  1. 対応サイトでデッキのページを開く。
    DECK MAKER はデッキの画像が出そろってから。
  2. ブックマーク「untapへ転送」をクリック。
    右上にパネルが出て、ページ内のデッキが並びます。初回だけ英語名データの取得に時間がかかります（ワンピース数秒、遊戯王は約100MBで10秒ほど、デュエマ・ヴァンガードはカード数に応じて数秒〜数十秒。ポケモンは内蔵なので待ちなし）。
  3. 使いたいデッキの「コピー」を押す。
  4. untap.in で同じゲームのデッキを開き、もう一度ブックマーク「untapへ転送」を押して「コピーしたデッキを取り込む」。
    • 貼り付け・「Clear existing cards in deck」のチェック・「Import Cards」まで自動で行い、デッキ名も入れます
    • 最初の1回だけ、Chrome から「クリップボードの読み取り」の許可を聞かれるので「許可」を
    • 取り込めなかったカードは一覧で出て、名前を押すと調べるページが開きます
    • 最後に untap 右上の「Save」を押して保存
    • 手動でやる場合は、Import / Export → Paste Deck に貼り付け →「Clear existing cards in deck」にチェック →「Import Cards」→「Save」
  5. 既存のカードを入れ替えるなら「Clear existing cards in deck」にチェック
  6. 「Import Cards」→ 最後に「Save」

ワンピースは型番を角括弧 [ ] で書くのがポイント（丸括弧だと同名の別カードに差し替わることがある）。遊戯王・ポケモン・デュエマ・ヴァンガードは名前で照合されます（ヴァンガードは丸括弧のカード番号で、untap に同じ版があればその版が入ります）。

ヴァイスシュヴァルツの使い方

日本版のヴァイスは英語名の公式データがなく、untap の登録名もファン翻訳のため、自動変換はしていません。代わりに、パネル上で英語名を確認・入力して貼り付け用テキストを作ります。一度入れた英語名はブラウザに保存され、次から自動で入ります。

  1. 公式のデッキレシピか DECK LOG のページでブックマークをクリックし、デッキの「開く」を押す。
    カードごとに「枚数・日本語名・カード番号」と、「HoC」「画像」のリンクが並びます。
  2. 「HoC」を押して英語名を確認し、入力欄に貼る。
    • Heart of the Cardsのそのカードのページが開きます。ページ上部のカード名（例："Bath Time" Rize）が英語名で、untap の登録名もたいていこれと同じです
    • untap の検索で見つかるか不安なら、キャラ名の英語（例：kotone）で untap を検索して画像で確かめてから入れてください
    • 入力しない行は日本語名のまま出力します。untap に日本語名でカスタム登録してあるカードは、空欄のままで取り込めます
  3. 「untap用にコピー」→ untap の Paste Deck に貼り付け。
    取り込めなかったカードは untap の「Cards Failed Import」に出ます。
  4. untap に無いカードはカスタム登録する。
    • 「カスタム登録用の一覧をコピー」で、英語名が空欄のカードの「番号・日本語名・画像URL・HoCのURL」を表形式でコピーできます（スプレッドシートに貼れます）
    • 画像は「画像」リンク（公式のカード画像）から保存してアップロード、カードテキストは HoC の英訳を使えます
    • 英語版が出ているカードは公式（official）として登録を
    • untap の登録は全ユーザーに公開され、登録者のアカウントに記録されます

保存した英語名は、サイトごと・ブラウザごとに別々です（公式サイトと DECK LOG で別）。パネルの「英語名データを書き出す」で ws-names.json に保存でき、「読み込む」で別のサイトや別の PC に移せます。書き出したファイルを GitHub のリポジトリ（d2u.js と同じ場所）にアップロードしておくと、どのサイト・どの PC でも自動で読み込まれ、バックアップにもなります。

英語名が見つからないカードの調べ方

パネルにオレンジ色で出たカードは、英語名に変換できなかったカードです（新しいカードに多い）。オレンジのカード名を押すと、そのカードを調べるページが開きます。英語のページは、Chrome なら右クリック →「日本語に翻訳」で読めます。

  1. オレンジのカード名を押して、英語名を確認する。
    • ONE PIECE：公式の英語版カードリストが型番で開きます。カードの名前が英語名です。
    • 遊戯王：Yugipedia（英語のwiki）の検索結果が開きます。一番上の項目が英語名。開いたページに日本語名も載っているので、合っているか確かめられます。
    • ポケモン：Limitlessの日本版カード一覧が開きます。カードを押すと英語名が出ます。
    • デュエマ：Duel Masters Wikiの検索結果が開きます。ページ名が英語名で、ページ内の「Japanese」の欄で日本語名を確かめられます。
    • ヴァンガード：Cardfight!! Vanguard Wikiの検索結果が開きます。ページ名が英語名です。「(D Series)」のような末尾のカッコ書きは名前に含めません。
  2. untap のデッキ画面で追加する。
    左上の検索欄（Search cards）に英語名を入れて検索し、出てきたカードをデッキに追加します。英語名は最初の数文字だけでも候補が出ます。
  3. untap で見つからないときは、untap にまだ登録されていないカードです。
    その場合は似た役割のカードで代用するか、untap の「Add Missing Card」から登録を依頼できます（登録はユーザー投稿なので反映は後日）。

知っておくこと

  • 英語名ワンピース：punk-records（3日保存）、遊戯王：yaml-yugi（7日保存）をその場で取得。ポケモン：Limitless の日本版カード一覧から作った対応表（2023年以降の弾・1747種、2026/9/23時点）を内蔵。トレーナーズは英語版の正式名です。デュエマ：英語のファンwiki（Duel Masters Wiki）をその場で検索し、カードページの日本語名と一致したものだけ使います（30日保存）。ヴァンガード：英語のファンwiki（Cardfight!! Vanguard Wiki）をカード番号で引き、見つからなければ日本語名で照合します（30日保存）。
  • オレンジ表示英語名が見つからないカード。日本語名のまま出力するので、untap 側で「取り込み失敗」になります。上の「英語名が見つからないカードの調べ方」を見て手で追加してください。
  • ポケモンの版untap のポケモンは名前でカードを選びます。ポケカ公式のデッキは日本版の弾コードも付けるので、untap に同じ弾の登録があればその版が入ります。弾コードがない場合（cardrush・TCG PORTAL 経由も含む）は名前だけで選ばれ、同じ名前で技が違う別の版になることがあります。
  • 新しい弾ポケモンの対応表は作成時点のものです。新弾のカードや、日本先行の遊戯王カードは変換・取り込みに失敗することがあります。デュエマは、wiki に載っていない新カードはオレンジ表示に、wiki にあっても untap に未登録のカードは untap 側で「取り込み失敗」になります。
  • ワンピースの取り込み後ごくまれに別の版が入ることがあります。セット表示（例：OP17）が型番と合っているか、ざっと確認を。
  • エラー「英語名データの一覧を取得できませんでした」は GitHub の回数制限（1時間あたり）。しばらく空けて再実行してください。
  • 履歴untap で取り込んだデッキは、untap の画面でブックマークを押したときのパネルに「履歴」として最大100件残ります（デッキ名・成績・元のページつき）。untap の無料プランはデッキを10個までしか保存できないので、入れ替えたデッキもここから「このデッキに取り込む」ですぐ戻せます。「デッキ名をコピー」もできます。
  • ドン!!ワンピースは通常のドン!!（Don!! Card (don-000)）10枚を DON Deck に自動で入れます。好きなドン!!を使うときは、コピー後に出る「ドン!!カード」欄に untap で検索したドン!!の「名前 (版)」（例：Don!! Card - Luffy (op01)）を入れて「保存して再コピー」。次回からもそのドン!!になります。
  • 対戦用メモコピー後に出る「対戦用メモをコピー」で、元のページの URL と「英語名 → 日本語名」の一覧をコピーできます。untap のデッキ画面の「Play Notes」タブに貼っておくと、対戦中に日本語名を確認できます。
  • デッキを比べる「別のデッキと比べる」に、untap の「Export Deck」の中身や別のページでコピーした内容を貼ると、何が何枚違うかを表示します（環境デッキの更新に合わせて自分のデッキを直すときなどに）。
  • 枚数チェックコピーすると、ゲームごとの決まった枚数（ワンピース50＋リーダー1、ポケモン60、遊戯王メイン40〜60、デュエマ40、ヴァンガード50＋ライド4〜5、ヴァイス50）と比べた結果が出ます。合わないときはページの読み取り漏れの可能性があります。
  • うまく動かないパネルのエラーの下、またはパネル下部の「報告用にコピー」を押すと、版・ページの URL・エラー内容・読み取れた件数がまとめてコピーされます。そのまま作った人に送ってください。
